- Bugs and feature requests: [Subtitle Doctor issues](https://github.com/AlinTibi/SubtitleDoctor/issues).
- Private security reports: [security@almarfeld.com](mailto:security@almarfeld.com).
- General ALMARFELD enquiries: [contact@almarfeld.com](mailto:contact@almarfeld.com).

For bugs, include the application version, Windows version, reproduction steps,
and expected and actual results. Use a small non-sensitive sample when helpful.
Remove personal information from screenshots and logs. Support is provided as
maintenance time permits, without a guaranteed response time.
